## Purpose

Remove remaining `react-redux` `connect()` HOC usage in Grafana’s frontend so components use typed `useSelector` / `useDispatch` from `app/types/store`, matching the hooks-first pattern already dominant in newer features.

**Done means:** zero files under `public/app/` importing `connect` from `react-redux` (starting count **38** on 2026-08-04).

**Out of scope (do not touch):**

- `getBackendSrv` → `@grafana/api-clients` migration (see Open questions)
- Redux slice/reducer/thunk rewrites; dashboard→Scenes; variables model redesign
- Removing the `react-redux` package / Provider
- Backend/Go; intentional UX/behavior changes
- Anything not in the inventory of `connect`-importing files below

Coverage baseline: Static inventory only (coverage run declined / not requested). Of 38 targets, ~18 have adjacent `*.test.*`; ~20 do not (admin pages, several Explore containers, variables editors, support-bundles, etc.). Characterization units precede migration of untested groups.

Constraints applied:

- Rung 3 → parallel fan-out allowed after pilot + lever
- Feature work continues → ratchet early (Stage 1)
- Untested touch points → characterization before change
- Medium risk → small directory-scoped PRs; no feature flag for pure wiring
- Behavior-changing flips none expected; Stage 4 is lint/docs only

## Strategy

Strangle `connect` directory-by-directory. Land a **count ratchet** first so new usage cannot grow while feature work continues. Add **characterization tests** for files without adjacent tests, then run a **human-in-the-loop pilot** on 2–3 simple functional components and encode the result in `spec.md`. Build a **small lever** (codemod or AST script) for the common functional pattern; convert **class components by hand** in late units. Fan-out by feature folder (parallel-safe). Finish by **ESLint-banning** `connect` imports and updating the Redux style guide.
